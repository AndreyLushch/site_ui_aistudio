# «Настолки» — Публичный сайт и витрина игр в Telegram

Интерактивный прототип публичного веб-сайта платформы «Настолки»: витрина настольных игр для живой компании внутри Telegram (Mini App) и магазин жетонов с оплатой картой или через СБП в рублях.

Репозиторий проекта: `AndreyLushch/site_ui_aistudio`.

---

## 1. Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 3000)
npm run dev

# Проверка сборки TypeScript и Vite
npm run build

# Запуск модульных тестов логики (node:test)
npx tsx --test src/utils/code.test.ts src/api/MockAdapter.test.ts
```

## 5. Иллюстрации и условные цены

Все цены в рублях являются **условными демонстрационными заглушками** для прототипа:
- Стартовый пакет (10 жетонов) — 199 ₽
- Стандартный пакет (20 жетонов) — 379 ₽
- Премиум пакет (50 жетонов, «Выгодно») — 899 ₽

Заглушки иллюстраций и визуальных обложек оформлены градиентными подложками с указанием необходимого арта:
- `guesser`: песочные часы, карточки слов, круглый стол с компанией.
- `pantomime`: маски, жесты рук, тёплый театральный свет.
- `shelter`: герметичная дверь бункера, мониторы с оценками ИИ.
- `tractor`: сцена шоу, микрофон, карточки жюри с оценками 1–5.
- `gangs`: ночной нуарный город, силуэты в шляпах, полицейский жетон.
- `spy`: чемоданчик, карта локации, увеличительное стекло.
- `associations`: сюрреалистичные парящие картины, луна, ключ.

## 6. Предложения сверх контракта (§9)

В DevPanel (вкладка «Предложения») и в прототипе реализованы и предложены следующие расширения:

| Предложение | Описание | Какие поля или методы адаптера нужны |
|---|---|---|
| **Подарочная открытка с кодом** | Готовый к печати и экспорту сертификат с кодом, инструкцией и именем получателя | Добавлен в UI: кнопка «Подарочная открытка» в заказе и `GiftCardPreviewModal` |
| **Тематические подборки игр** | Быстрые фильтры «На двоих», «Для вечеринки/корпоратива», «Разминка» | Расширение поля `tags: string[]` у `SiteGame` |
| **Калькулятор жетонов на вечер** | Интерактивный расчёт: сколько человек и часов → сколько партий и жетонов понадобится | Уже интегрирован на главной странице; использует ступени партий |
| **Решения для заведений (B2B)** | Пакеты и брендированные тейблтенты с QR для баров и антикафе с безлимитом | Метод `getVenueSubscription()` в `SiteAdapter` |
